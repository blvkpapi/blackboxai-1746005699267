# Social Media Optimization Mobile App

This is a React Native mobile application built with Expo for social media optimization. The app includes features for scheduling posts, content suggestion, engagement tracking, and analytics. It integrates with social media platforms like Instagram, Twitter, and Facebook to acquire data.

## Features

- Schedule posts with calendar and time picker
- Content suggestion module
- Engagement tracking dashboard
- Analytics with charts and metrics
- Integration with Instagram, Twitter, Facebook APIs (authentication required)
- Simulated data for WhatsApp due to API limitations

## Getting Started

### Prerequisites

- Node.js and npm installed
- Expo CLI installed globally (`npm install -g expo-cli`)
- A mobile device with Expo Go app installed or an emulator/simulator set up

### Installation

1. Clone the repository or download the project files.
2. Navigate to the project directory.
3. Run `npm install` to install dependencies.
4. Start the Expo development server with `expo start`.
5. Use the Expo Go app on your mobile device or an emulator to run the app.

### Running the App

- Scan the QR code displayed in the terminal or Expo DevTools with your mobile device.
- The app will load and you can navigate through the features using the bottom tab navigator.

## Notes

- API keys and authentication setup for social media platforms will be required for full functionality.
- WhatsApp integration is simulated due to API restrictions.
